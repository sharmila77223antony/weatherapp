# 🌤️ Sharmi Sky

Sharmi Sky is a modern weather application featuring a premium liquid-glass design, beautiful animations, and real-time weather updates.

### 🌐 Live Demo
🔗 [**Visit Sharmi Sky**](https://weatherapp-git-main-sharmila-dev.vercel.app/)

### ✨ Features
- 🌡️ Current weather conditions
- 🕒 Hourly weather forecast
- 📅 7-day weather forecast
- 🌙 Animated day and night themes
- 💎 Premium glassmorphism UI
- 📱 Responsive design

### 🛠️ Tech Stack
React.js • JavaScript • CSS • Open-Meteo API

### 🚀 Getting Started
```bash
npm install
npm run dev
```
